# 🐤 小目标

> **一个人也能认真完成目标的安静角落。**
> 完全免费 · 无付费墙 · 无焦虑制造机 · 数据在你手上

「小目标」是 PlanJoy 的免费复刻版 + 全日健康生态的第七块拼图 —— 手机优先的 PWA 网页应用。

## ✨ 功能一览

| 模块 | 说明 |
|------|------|
| 🎯 目标管理 | 三种类型：量化型 / 习惯型 / 里程碑型，无限数量 |
| ✅ 每日打卡 | 一键打卡、量化记录、批量打卡、补卡（每月3次） |
| 📅 打卡日历 | 月视图、颜色标记、单目标日历 |
| 📊 四象限 | 重要/紧急 2×2 矩阵（PlanJoy 付费功能，这里免费） |
| 🍅 番茄钟 | 15/25/45 分钟 + 白噪音（雨声/篝火/海浪，Web Audio 生成） |
| 📈 统计报表 | 完成率、连续天数、分类分布、成就徽章 |
| 🐤 **虚拟宠物** | **SVG 可视化小胖鸭**：会眨眼/浮动/摇摆，可摸摸/喂食/聊天，5 种等级外观（星星鸭/火焰鸭/皇冠鸭/樱花鸭），**只奖励不惩罚，永不伤心** |
| 🤖 AI 目标拆解 | 用自己的 API Key，AI 把大目标拆成里程碑计划（稳定 JSON 输出） |
| 🛡️ **API 保护** | 本地代理转发 + 公网护栏（访问令牌/域名白名单/服务端持Key/限流） |
| 📦 模板库 | 12 个内置模板（读书/减重/攒钱/早睡/冥想...） |
| 💾 数据主权 | 全部本地存储 + JSON 导出/导入 |
| 📱 PWA | 离线可用、添加到主屏幕即原生体验 |

## 🚀 快速开始

```bash
node server.js            # 需要 Node.js ≥ 14
# 打开 http://localhost:3111
```

手机同 Wi-Fi 访问 `http://192.168.x.x:3111`。
公网部署与 API 保护详见 [部署指南.md](部署指南.md)。

## 🏗️ 技术架构

```
app/
├── index.html            # SPA 骨架（6 页 + 底部导航）
├── css/style.css         # 手账感设计（暖木色 + 鸭黄）
├── js/
│   ├── data/             # API 预设 / 模板库 / 鸭鸭文案
│   ├── utils/
│   │   ├── icons.js      # Feather 开源 SVG 图标（MIT）
│   │   ├── store.js      # localStorage 存储层
│   │   ├── duckArt.js    # SVG 小胖鸭形象（5 等级 × 6 表情）
│   │   └── llm.js        # AI 调用层（代理优先，自动回退直连）
│   └── app.js            # 主应用（路由/目标/打卡/宠物/四象限/番茄钟/统计）
├── server.js             # 网页服务 + API 保护代理（四道公网护栏）
├── service-worker.js     # PWA 离线缓存
├── manifest.json         # PWA 清单
└── assets/               # 小胖鸭图标（make_icons.py 生成）
```

**核心设计原则**
- 纯前端零依赖，无任何付费服务，无埋点
- 数据 100% 本地存储，导出免费，数据主权归用户
- 虚拟宠物只正向激励：没打卡它只说"欢迎回来"，从不扣血、从不死亡
- API Key 经本地代理转发（服务端持 Key 模式可选），公网部署有完整护栏
